# 台风实况和路径

> 来源：和风天气开发者文档（https://dev.qweather.com/docs/api/tropical-cyclone/storm-track/）

台风实况和路径API提供全球主要海洋流域的台风实时位置、等级、气压、风速以及活跃台风的轨迹路径。

## 请求路径

```
GET /v7/tropical/storm-track
```

## 参数

#### 查询参数

* stormid 必选

  string

  需要查询的台风ID，StormID可通过[台风查询API](/docs/api/tropical-cyclone/storm-list/)获取。例如 `stormid=NP2018`

## 请求示例

```
curl -X GET --compressed \
-H 'Authorization: Bearer your_token' \
'https://your-api-host/v7/tropical/storm-track?stormid=NP2018'
```

请将`your_token`替换为你的[JWT身份认证](/docs/configuration/authentication/)，将`your_api_host`替换为你的[API Host](/docs/configuration/api-host/)
