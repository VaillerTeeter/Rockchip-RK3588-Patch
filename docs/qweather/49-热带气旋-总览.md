# 热带气旋（台风）

> 来源：和风天气开发者文档（https://dev.qweather.com/docs/api/tropical-cyclone/）

热带气旋 API 提供中国地区的台风信息，包括台风实时位置、路径和预报数据。

## API

[GET台风预报](/docs/api/tropical-cyclone/storm-forecast/)

获取全球主要海洋流域中指定台风的预测位置、等级、气压和风速等数据。

[GET台风实况和路径](/docs/api/tropical-cyclone/storm-track/)

获取全球主要海洋流域中指定台风的实时位置、强度及路径数据。

[GET台风列表](/docs/api/tropical-cyclone/storm-list/)

获取全球主要海洋流域最近2年的台风列表。
