# 天文

> 来源：和风天气开发者文档（https://dev.qweather.com/docs/api/astronomy/）

天文API提供了全球任意地点未来60天的日出日落、太阳高度角、月升月落和月相数据，

## API

[GET日出日落](/docs/api/astronomy/sunrise-sunset/)

获取全球任意地点未来60天的日出日落时间。

[GET月升月落和月相](/docs/api/astronomy/moon-and-moon-phase/)

获取全球城市未来60天的月升月落时间和逐小时月相数据。

[GET太阳高度角](/docs/api/astronomy/solar-elevation-angle/)

获取全球任意地点在指定时间的太阳高度角和方位角。
