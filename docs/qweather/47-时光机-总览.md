# 时光机

> 来源：和风天气开发者文档（https://dev.qweather.com/docs/api/time-machine/）

时光机可以获取最近10天的历史天气。

> 和风天气额外提供了2000年至今的历史再分析气象数据，通过数据文件的形式发送，如需要长时间的历史气象数据数据，请提供下列信息，发送邮件至sales@qweather.com，我们将有专人与你联系:
>
> * 企业名称
> * 联系方式
> * 所需要的城市或坐标
> * 所需要的时间范围

## API

[GET天气时光机](/docs/api/time-machine/time-machine-weather/)

获取最近10天的天气历史再分析数据。
