# 02 颜色配置 — 背景与文字色

> 来源文件：
> - `frameworks/base/core/res/res/values/colors.xml`（框架层）
> - `frameworks/base/packages/SystemUI/res/values/colors.xml`（SystemUI 层）
> 配置类型：`<color>` / `<drawable>`

本文档整理所有与顶部状态栏相关的颜色配置项，包括状态栏背景色、时钟文字颜色、梦境叠加层（Dream Overlay）文字阴影色等。

---

## 框架层颜色配置

> 文件：`core/res/res/values/colors.xml`

| 配置名 | 默认值 | 类型 | 描述 |
|--------|--------|------|------|
| `status_bar_closed_default_background` | `#ff000000`（纯黑） | `drawable` | 状态栏**收起**（正常显示）时的默认背景色 |
| `status_bar_opened_default_background` | `#ff000000`（纯黑） | `drawable` | 状态栏**展开**（下拉通知面板）时的默认背景色 |

### 原始 XML 片段

```xml
<!-- core/res/res/values/colors.xml -->

<!-- 状态栏收起时的默认背景 -->
<drawable name="status_bar_closed_default_background">#ff000000</drawable>

<!-- 状态栏展开时的默认背景 -->
<drawable name="status_bar_opened_default_background">#ff000000</drawable>
```

---

## SystemUI 层颜色配置

> 文件：`packages/SystemUI/res/values/colors.xml`

| 配置名 | 默认值 | 描述 |
|--------|--------|------|
| `status_bar_clock_color` | `#FFFFFFFF`（纯白） | 状态栏时钟文字颜色（同时也用于用户头像芯片文字） |
| `dream_overlay_status_bar_key_text_shadow_color` | `#66000000`（40% 黑） | 梦境叠加层状态栏文字在亮色背景下的阴影色 |
| `dream_overlay_status_bar_ambient_text_shadow_color` | `#59000000`（35% 黑） | 梦境叠加层状态栏文字在环境光模式下的阴影色 |

### 原始 XML 片段

```xml
<!-- packages/SystemUI/res/values/colors.xml -->

<!-- 时钟文字颜色（白色） -->
<color name="status_bar_clock_color">#FFFFFFFF</color>

<!-- 梦境叠加层状态栏文字阴影（亮色背景） -->
<color name="dream_overlay_status_bar_key_text_shadow_color">#66000000</color>

<!-- 梦境叠加层状态栏文字阴影（环境光模式） -->
<color name="dream_overlay_status_bar_ambient_text_shadow_color">#59000000</color>
```

---

## 修改建议

- **车机深色主题**：`status_bar_closed_default_background` 和 `status_bar_opened_default_background` 保持黑色即可，也可改为半透明（如 `#CC000000`）
- **修改时钟颜色**：修改 `status_bar_clock_color`，注意同步检查 `TextAppearance.StatusBar.Clock` 样式（见文档 06）
- **亮色状态栏**：若状态栏背景改为浅色，需同步将 `windowLightStatusBar` 设为 `true`（见文档 04），使图标切换为深色模式
