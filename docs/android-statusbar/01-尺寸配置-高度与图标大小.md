# 01 尺寸配置 — 高度与图标大小

> 来源文件：`frameworks/base/core/res/res/values/dimens.xml`
> 配置类型：`<dimen>`

本文档整理框架层（`core/res`）中所有与顶部状态栏相关的尺寸配置项。这些值决定了状态栏的物理高度、图标大小、触摸边距等视觉与交互参数。

> ⚠️ 注意：读取状态栏高度时，**不要直接读取这些 dimen**，应使用 `SystemBarUtils#getStatusBarHeight()` API，以便正确处理刘海屏等异形屏场景。

---

## 配置项列表

| 配置名 | 默认值 | 描述 |
|--------|--------|------|
| `status_bar_height_default` | `24dp` | 状态栏的默认高度基准值，用于 `SystemBarUtils#getStatusBarHeight()` 计算时的回退值 |
| `status_bar_height` | `@dimen/status_bar_height_portrait` | 状态栏高度（别名），实际指向竖屏高度值；**不要直接读取，使用 API** |
| `status_bar_height_portrait` | `24dp` | 竖屏方向下的状态栏高度；**不要直接读取，使用 API** |
| `status_bar_height_landscape` | `@dimen/status_bar_height_portrait` | 横屏方向下的状态栏高度，默认与竖屏相同；**不要直接读取，使用 API** |
| `status_bar_icon_size` | `22dip` | 通知图标在状态栏中的显示高度 |
| `status_bar_system_icon_size` | `15dp` | 系统状态图标（WiFi、电池等）的期望显示尺寸 |
| `status_bar_system_icon_intrinsic_size` | `17dp` | 系统状态图标的固有尺寸默认值，当 Drawable 报告固有尺寸为 0 时使用此值 |
| `status_bar_content_number_size` | `48sp` | 通知未读数字（大数字）的字体大小 |
| `status_bar_edge_ignore` | `5dp` | 状态栏下拉展开时，屏幕边缘忽略触摸事件的宽度（防误触） |

---

## 原始 XML 片段

```xml
<!-- core/res/res/values/dimens.xml -->

<!-- 默认高度基准值，用于 SystemBarUtils 计算回退 -->
<dimen name="status_bar_height_default">24dp</dimen>

<!-- 状态栏高度别名，指向竖屏值 -->
<dimen name="status_bar_height">@dimen/status_bar_height_portrait</dimen>

<!-- 竖屏状态栏高度 -->
<dimen name="status_bar_height_portrait">24dp</dimen>

<!-- 横屏状态栏高度（默认同竖屏） -->
<dimen name="status_bar_height_landscape">@dimen/status_bar_height_portrait</dimen>

<!-- 通知图标高度 -->
<dimen name="status_bar_icon_size">22dip</dimen>

<!-- 系统图标期望尺寸 -->
<dimen name="status_bar_system_icon_size">15dp</dimen>

<!-- 系统图标固有尺寸默认值 -->
<dimen name="status_bar_system_icon_intrinsic_size">17dp</dimen>

<!-- 通知未读大数字字号 -->
<dimen name="status_bar_content_number_size">48sp</dimen>

<!-- 边缘触摸忽略宽度 -->
<dimen name="status_bar_edge_ignore">5dp</dimen>
```

---

## 修改建议

- **车机定制状态栏高度**：修改 `status_bar_height_portrait`，横竖屏通常保持一致，同步修改 `status_bar_height_landscape`
- **放大图标**：同步调整 `status_bar_icon_size` 和 `status_bar_system_icon_size`，保持比例协调
- **高分辨率屏幕**：`status_bar_system_icon_intrinsic_size` 可适当上调，避免图标模糊
