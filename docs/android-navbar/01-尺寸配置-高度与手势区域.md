# 01 尺寸配置 — 高度与手势区域

> 来源文件：
> - `frameworks/base/core/res/res/values/dimens.xml`（Framework 层）
> - `frameworks/base/packages/SystemUI/res/values/dimens.xml`（SystemUI 层）
>
> 配置类型：`<dimen>`

本文档整理框架层与 SystemUI 层中所有与底部导航栏相关的尺寸配置项，涵盖导航栏高度/宽度、Car Mode 尺寸、手势触发区域、Home Handle 尺寸、边缘返回面板尺寸等。

---

## Framework 层配置项

来源：`core/res/res/values/dimens.xml`

| 配置名 | 默认值 | 描述 |
|--------|--------|------|
| `navigation_bar_height` | `48dp` | 导航栏高度（竖屏），同时也是上报给其他窗口用于布局避让的高度 |
| `navigation_bar_height_landscape` | `48dp` | 导航栏高度（横屏），通常与竖屏相同 |
| `navigation_bar_width` | `48dp` | 导航栏竖置于屏幕侧边时的宽度 |
| `navigation_bar_frame_height` | `@dimen/navigation_bar_height` | 导航栏窗口帧高度，上报给 SystemUI 导航栏 View 的窗口；与 `navigation_bar_height` 的区别在于此值是 SystemUI 窗口实际大小，而前者是上报给其他窗口的避让高度 |
| `navigation_bar_frame_height_landscape` | `@dimen/navigation_bar_frame_height` | 横屏导航栏窗口帧高度 |
| `navigation_bar_gesture_height` | `@dimen/navigation_bar_frame_height` | 手势导航模式下底部手势触发区的高度 |
| `navigation_bar_gesture_larger_height` | `80dp` | 手势导航模式下更大的底部手势触发区高度（用于更宽松的手势识别） |
| `navigation_bar_height_car_mode` | `96dp` | Car Mode（车载模式）下导航栏高度 |
| `navigation_bar_height_landscape_car_mode` | `96dp` | Car Mode 横屏导航栏高度 |
| `navigation_bar_width_car_mode` | `96dp` | Car Mode 导航栏竖置时的宽度 |

## SystemUI 层配置项

来源：`packages/SystemUI/res/values/dimens.xml`

### 基础尺寸

| 配置名 | 默认值 | 描述 |
|--------|--------|------|
| `navigation_bar_size` | `@*android:dimen/navigation_bar_height` | 导航栏厚度（高度），引用 Framework 层的 `navigation_bar_height` |
| `navigation_bar_deadzone_size` | `12dp` | 导航栏顶部死区高度（约 2mm），用于防止误触导航按钮 |
| `navigation_bar_deadzone_size_max` | `32dp` | 屏幕其他区域近期有触摸时，死区扩展到的最大高度 |

### Home Handle 尺寸（手势导航模式）

| 配置名 | 默认值 | 描述 |
|--------|--------|------|
| `navigation_handle_radius` | `2dp` | 手势导航 Home Handle（底部横条）的圆角半径 |
| `navigation_handle_bottom` | `10dp` | Home Handle 距屏幕底部的距离 |
| `navigation_handle_sample_horizontal_margin` | `10dp` | Home Handle 水平方向的采样边距 |
| `navigation_home_handle_width` | `108dp` | Home Handle 的宽度 |

### 边缘返回手势面板尺寸

| 配置名 | 默认值 | 描述 |
|--------|--------|------|
| `navigation_edge_panel_width` | `105dp` | 边缘返回手势触发面板的宽度，应大于边缘灵敏度加拖拽阈值之和 |
| `navigation_edge_panel_height` | `268dp` | 边缘返回手势触发面板的高度 |
| `navigation_edge_panel_padding` | `8dp` | 边缘面板末端的 padding，防止返回箭头被裁切 |
| `navigation_edge_action_drag_threshold` | `16dp` | 触发边缘返回手势所需的最小拖拽距离 |
| `navigation_edge_action_min_distance_to_start_animation` | `24dp` | 开始播放返回动画所需的最小拖拽距离 |
| `navigation_edge_action_progress_threshold` | `412dp` | 返回动画进度评估的拖拽距离阈值 |
| `navigation_edge_arrow_min_y` | `64dp` | 返回箭头在屏幕上的最小 Y 坐标（防止箭头超出屏幕顶部） |
| `navigation_edge_finger_offset` | `64dp` | 返回箭头相对手指的偏移量（避开手指遮挡） |
| `navigation_edge_action_reactivation_drag_threshold` | `32dp` | 动态重新激活边缘手势所需的拖拽阈值 |
| `navigation_edge_action_deactivation_drag_threshold` | `32dp` | 动态停用边缘手势所需的拖拽阈值 |
| `navigation_edge_arrow_thickness` | `4dp` | 返回箭头线条的粗细 |
| `navigation_edge_minimum_x_delta_for_switch` | `32dp` | 改变边缘手势方向或停止触发返回所需的最小 X 轴位移量 |

### IME 相关

| 配置名 | 默认值 | 描述 |
|--------|--------|------|
| `navbar_back_button_ime_offset` | `2dp` | IME（输入法）模式下返回按钮的偏移量 |

## 修改建议

- **车机定制导航栏高度**：修改 `navigation_bar_height`，横竖屏通常保持一致，同步修改 `navigation_bar_height_landscape`；同时同步修改 `navigation_bar_frame_height`（若需要窗口帧与避让高度不同）
- **Car Mode 高度**：若系统运行在 Car Mode 下，需同步修改 `navigation_bar_height_car_mode` 和 `navigation_bar_height_landscape_car_mode`
- **调整手势触发灵敏度**：修改 `navigation_edge_action_drag_threshold` 可降低/提高边缘返回手势的触发难度
- **调整 Home Handle 大小**：修改 `navigation_home_handle_width` 可改变底部横条的宽度
