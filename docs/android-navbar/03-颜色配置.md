# 03 颜色配置

> 来源文件：
> - `frameworks/base/core/res/res/values/colors_device_defaults.xml`（Framework 层）
> - `frameworks/base/packages/SystemUI/res/values/colors.xml`（SystemUI 层）
>
> 配置类型：`<color>`

本文档整理框架层与 SystemUI 层中所有与底部导航栏相关的颜色配置项，涵盖导航栏图标颜色、Home Handle 颜色（浅色/深色模式）、分割线颜色。

> ⚠️ 注意：这些是资源层的颜色定义，App 可通过 Window 属性（`navigationBarColor` 等）覆盖导航栏背景色，详见 [04-Window属性-navigationBarColor等](./04-Window属性-navigationBarColor等.md)。

---

## 配置项列表

| 配置名 | 来源文件 | 默认值 | 描述 |
|--------|----------|--------|------|
| `navigation_bar_divider_device_default_settings` | `colors_device_defaults.xml` | `#1f000000`（12% 透明黑） | 设置页面中导航栏顶部分割线的颜色，用于在浅色背景下区分导航栏与内容区域 |
| `navigation_bar_icon_color` | `SystemUI/colors.xml` | `#E5FFFFFF`（90% 透明白） | 导航栏按钮图标的颜色（返回、Home、最近任务图标） |
| `navigation_bar_home_handle_light_color` | `SystemUI/colors.xml` | `#EBffffff`（92% 透明白） | 手势导航模式下 Home Handle（底部横条）的浅色版本（白色），用于**深色背景**上 |
| `navigation_bar_home_handle_dark_color` | `SystemUI/colors.xml` | `#99000000`（60% 透明黑） | 手势导航模式下 Home Handle（底部横条）的深色版本（黑色），用于**浅色背景**上 |

---

## 原始 XML 片段

```xml
<!-- core/res/res/values/colors_device_defaults.xml -->

<!-- 设置页面导航栏分割线颜色（半透明黑） -->
<color name="navigation_bar_divider_device_default_settings">#1f000000</color>
```

```xml
<!-- packages/SystemUI/res/values/colors.xml -->

<!-- 导航栏按钮图标颜色（高透白） -->
<color name="navigation_bar_icon_color">#E5FFFFFF</color>

<!-- Home Handle 浅色模式颜色（白色，用于深色背景） -->
<color name="navigation_bar_home_handle_light_color">#EBffffff</color>

<!-- Home Handle 深色模式颜色（黑色，用于浅色背景） -->
<color name="navigation_bar_home_handle_dark_color">#99000000</color>
```

---

## 修改建议

- **深色主题车机**：`navigation_bar_icon_color` 默认为白色，适合深色导航栏背景；若导航栏背景为浅色，应将图标颜色改为深色（如 `#99000000`），或通过 `windowLightNavigationBar` 属性自动切换（详见文档 04）
- **调整 Home Handle 可见度**：若车机壁纸颜色固定，可将 `navigation_bar_home_handle_light_color` 和 `navigation_bar_home_handle_dark_color` 统一设为与背景对比度高的颜色，提升可见性
- **隐藏分割线**：将 `navigation_bar_divider_device_default_settings` 设为 `@android:color/transparent` 可去除设置页面中导航栏的分割线
